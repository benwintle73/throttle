# Throttle

One-button neon rooftop motorbike game. Tap to hop (tap again in the air for nitro), hold to backflip, land flat or wipe out.

**Play:** https://benwintle73.github.io/throttle/

Single `index.html`: Three.js 0.147 with bloom, procedural city, Web Audio synth sound, no build step. Best score saves in the browser.

Status: core prototype for play-testing. Planned next: mid-run perks, daily course with ghost rider and leaderboard, unlockable bikes.
